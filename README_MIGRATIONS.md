# Миграции базы данных

Для управления миграциями используется Alembic.

## Запуск миграций

```bash
# Применить все миграции
alembic upgrade head

# Откатить одну миграцию назад
alembic downgrade -1

# Откатить все миграции
alembic downgrade base
```

## Создание новой миграции

```bash
# Автоматическая генерация миграции на основе изменений моделей
alembic revision --autogenerate -m "Описание изменений"

# Или создание пустой миграции
alembic revision -m "Описание изменений"
```

## Просмотр состояния

```bash
# Показать текущую ревизию
alembic current

# Показать все миграции
alembic history
```

## Структура миграций

- `001_initial_schema.py` - начальная схема (таблицы users и counter)
- `002_add_user_management.py` - добавление полей created_at и is_active для управления пользователями

## Изменения в схеме

### Таблица users
- id - первичный ключ
- username - уникальное имя пользователя
- password_hash - хэш пароля
- created_at - дата создания записи
- is_active - флаг активности пользователя

### Таблица counter
- id - первичный ключ
- user_id - внешний ключ на users.id
- value - значение счетчика (у каждого пользователя свое)
